# Donya

Donya is a desktop music player for browsing and playing a local music library from folders on your device.

## Features

- Add one or more music folders and scan them into a local library.
- Browse your tracks by Home, Albums, Artists, and Favorites.
- Play music with queue, shuffle, repeat, and volume controls.
- Manage favorite tracks and library sources in Settings.

## Development

Install dependencies and run the app in development mode:

```bash
npm install
npm run dev
```

To run the desktop app with Tauri:

```bash
npm run tauri dev
```

## Build

Create a production build for the web frontend:

```bash
npm run build
```

To build the desktop application package:

```bash
npm run tauri build
```
